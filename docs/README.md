## Reference and record

The [architecture's canonical-document table](ARCHITECTURE.md#5-canonical-documents)
assigns each topic a home. [Evidence conventions](ARCHITECTURE.md#evidence-conventions)
explain the separate confidence scales and how to read claims.

[REA notes](../REA-NOTES-59638.md) and [the investigation log](../REPLAY-RESEARCH.md)
retain the historical analysis. Per-topic findings, reproduction scripts and raw
evidence are indexed under [research](../research/INDEX.md); plans and session
archives retain their original context. Later corrections do not erase them.

For documentation maintenance decisions, see the dated
[review record](DEVELOPMENT-REVIEW.md).
